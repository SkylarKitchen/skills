# Design

Skills for visual work: drawings, diagrams, and interactive pages.

## Model-invoked

Reachable by you or by the agent when a task fits.

- **[3d-assembly-manual](./3d-assembly-manual/SKILL.md)**: Build a phone-first, step-by-step 3D build guide (LEGO-manual pacing, BIG-diagram look) as a single Three.js HTML file, from a starter engine you only configure.
- **[launch-film](./launch-film/SKILL.md)**: Make a short, frame-exact product film for X or a portfolio from the real app, site or Three.js scene: an authored camera over the real surface, rendered on a canvas engine instead of cut from a screen recording.
- **[room-from-photos](./room-from-photos/SKILL.md)**: Turn a few phone photos of an existing room into a near-photoreal 3D model and plan, with furniture layouts to compare, fit checks, and a gizmo to drag pieces around, as a single Three.js HTML file.
