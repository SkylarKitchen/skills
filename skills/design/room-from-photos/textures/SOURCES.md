# Photo finishes

These are photo scans of real materials from [ambientCG](https://ambientcg.com). They are licensed CC0 1.0, which means public domain: no attribution is needed, and they can be copied, changed and shipped freely.

Each one was downloaded at 1K. The colour maps were converted to greyscale and stretched so their brightest pixel is about 250, because the engine tints them with each swatch. The normal maps are the OpenGL versions (NormalGL), and some were downsized to 512 px. The engine tiles each file at the real size in the last column.

| File | Source | Used for | One tile covers |
|---|---|---|---|
| `wood.jpg` | [Wood049](https://ambientcg.com/view?id=Wood049), colour map | Wood furniture, and the floor boards (turned 90°) | 31.5″ (80 cm) |
| `oak.jpg` | [Wood050](https://ambientcg.com/view?id=Wood050), colour map | Wall paneling planks (turned 90°) | 31.5″ (80 cm) |
| `fabric.jpg`, `fabric-n.jpg` | [Fabric036](https://ambientcg.com/view?id=Fabric036), colour and normal maps | Upholstery and lamp shades | about 5″ (estimated from the thread count, because ambientCG gives no size) |
| `brick.jpg`, `brick-n.jpg` | [Bricks060](https://ambientcg.com/view?id=Bricks060), colour and normal maps | Fireplace brick | 41.3″ (105 cm) |
| `carpet-n.jpg` | [Carpet016](https://ambientcg.com/view?id=Carpet016), normal map | Rug pile (the rug's pattern is still drawn) | 67″ (170 cm) |

You can replace a finish with any other greyscale scan, as long as you keep its file name and change its size in `SCANS` in `starter.html`.
